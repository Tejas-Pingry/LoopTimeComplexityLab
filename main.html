The garage Java only

Lap time = how long your code runs. Declare int count = 0; and tick count inside the innermost body of every loop. You can write loops, a sort, or both; free-standing loops run first, then static void sort(int[] a) runs on the race array and must leave it sorted. Every free-standing outermost loop must involve N (the array size from the slider; capital N), like for (int i = 0; i < N; i++) or for (int i = N; i >= 0; i--); nested loops can use i, and loops inside a sort can use a.length. Java subset: int, long, boolean, arrays, for, while, do-while, if, ternary, recursion, Math.*; integer division only; no casts, double, or imports. Over 4,000,000 ticks or 20 million loop iterations is a DNF.

Pit wall Java loop telemetry

Paste a Java loop. It must update count and may use n. The app runs it for a range of n, counts, plots, and fits a complexity class. Integer division and /= truncate like Java.

Pit lane experimental


20-lap endurance race. Every lap each car sorts its current array. Lap 1 of a pair is a fresh random set; lap 2 re-sorts that same, now sorted, set (insertion sort loves it, Lomuto quick sort hates it). After every second lap the car pits for 3 s and is handed a brand-new set. Lap time = count x 5 ms plus a base of N ticks for driving the circuit; pit stops are added on top. Includes your garage car.
