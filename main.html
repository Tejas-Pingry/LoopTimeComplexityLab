Timing tower

Lap time = array reads + writes (1 op = 0.5 ms). Animation time is square-root compressed so you can watch; the tower shows true times.

The garage Java only

Write static void sort(int[] a) in Java (helper methods allowed). Sort a in place. Every a[i] read or write costs 1 op, including arrays you create with new int[n]. Supported: int, long, boolean, arrays, for, while, if, ternary, recursion, Math.*. Integer division only. No casts, double, or imports.

Pit wall Java loop telemetry

Paste a Java loop. It must update count and may use n. The app runs it for a range of n, counts, plots, and fits a complexity class. Integer division and /= truncate like Java.

Pit lane experimental


Live sortedness race. In the main race every car moves at a steady pace, so nobody can ever overtake. Here, each car's position is the share of the array that is already in its final slot right now, sampled while its sort runs. Selection sort creeps forward steadily, Quick sort lurches, Merge sort stays near the back until its final merges. Cars genuinely pass each other. Best on Random grid order (sorted data starts out 100% sorted, so every car begins parked near the line).
